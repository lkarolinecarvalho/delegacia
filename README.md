# Delegacia

Jogo para aprender Direito Penal, Processo Penal e legislação penal especial do zero,
dentro de uma delegacia. Você é o(a) delegado(a) que acabou de tomar posse: os casos
chegam, você analisa o fato, decide e responde afirmativas no estilo de banca.

Em desenvolvimento. Nome provisório.

## Rodar

```
corepack enable
pnpm install
pnpm dev        # http://localhost:5174
```

`pnpm test`, `pnpm typecheck` e `pnpm lint` verificam o projeto.
